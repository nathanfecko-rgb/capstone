# Sports Central

Sports Central is a sports website built with HTML, CSS,
JavaScript, and Bootstrap 5.

## Pages
- Home
- Baseball
- Basketball
- Teams

## Features
- Responsive navigation bar
- Baseball and basketball team cards
- Sample scoreboards
- Searchable team list
- Bootstrap accordion
- Custom black and red theme

## How to Run
Open index.html in a web browser.

An internet connection is needed to load Bootstrap.

Note: The displayed scores are examples, not live results.
